# The UX Psychology Behind Apps People Can’t Stop Using

UXPeak video about using behavioural psychology to reduce abandonment in onboarding, forms, signup, pricing, upgrade prompts, and conversion moments.

The main point: good UX is not only visual polish. It makes the next action feel obvious, valuable, and worth completing.

## Core Ideas

- Empty forms create decision fatigue. Smart defaults turn the task from "fill this out" into "scan and adjust."
- Starting progress at 0% can feel deflating. Count something the user has already done so the flow starts with momentum.
- Give useful value before signup. A blurred report behind a signup wall feels like withholding; a partial useful report builds trust and reciprocity.
- Let users build or choose something before asking them to create an account. Investment and ownership make leaving feel like abandoning something.
- Loss framing can motivate action more strongly than gain framing, but should be used carefully and honestly.
- Prices feel different depending on the comparison shown immediately before them. Show costs in context, not isolation.

## Principles Covered

### Smart Defaults

Defaults act like recommendations. When the product already knows the common choice, pre-selecting it reduces cognitive effort and makes action easier.

### Goal Gradient Effect

People move faster when they feel closer to completion. Onboarding can use a real head start by counting an already completed action, such as account creation or first setup.

### Reciprocity

Users are more willing to sign up after they have received real value. The source contrasts locking results behind signup with showing a useful preview and then asking the user to save the full report.

### IKEA Effect and Endowment Effect

People value things more when they helped create them or feel ownership over them. Pre-signup customization can create investment before account creation.

### Loss Aversion

The pain of losing something is stronger than the pleasure of gaining something similar. Upgrade prompts can show the real cost of inaction, but the source warns against fake urgency, fake scarcity, fake progress, fake reviews, or other dark patterns.

### Contrast Effect

The first number becomes the reference point. A protection plan shown after a high-value product can feel smaller because the user evaluates it relatively.

## Durable Notes

- These principles overlap with [[Hook Model]] because investment increases switching cost and makes future action more likely.
- The ethical constraint matters: psychology should reduce confusion and build trust, not manipulate users.
- The practical design question is: what does the user need to see first so the next action feels easier, safer, or more worthwhile?
