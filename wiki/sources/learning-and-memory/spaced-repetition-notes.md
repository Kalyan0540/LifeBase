# How To Remember Anything Forever-ish — Notes

Notes on Nicky Case's interactive comic about [[Spaced Repetition]]: building durable memory through active recall and review intervals that expand after successful retrieval.

## Core argument

Memory supports creativity and critical thinking because useful ideas must be available for reasoning and creation. Durable learning comes from combining:

- **Active recall** — attempt the answer before checking it.
- **Spacing** — return to the material over time.
- **Increasing gaps** — wait longer after each successful recall because the memory decays more slowly.

The practical target is desirable difficulty: review when recall is effortful but still possible, or when the learner has “almost forgotten.”

## Why passive study underperforms

Lectures, cramming, and rereading can create familiarity without reliable retrieval. Spaced repetition makes retrieval itself the practice. A successful recall strengthens the memory, while a failed recall signals that the interval or card design needs adjustment.

## Leitner Box implementation

A Leitner Box places new cards in Level 1. Correct cards move up to a level with a longer interval; incorrect cards return to Level 1. The example schedule doubles the interval at each level:

| Level | Review gap |
|---|---:|
| 1 | 1 day |
| 2 | 2 days |
| 3 | 4 days |
| 4 | 8 days |
| 5 | 16 days |
| 6 | 32 days |
| 7 | 64 days |

The exact schedule matters less than the principle that successful recall earns a longer gap.

## Good flashcards

Effective cards are:

- **Small** — one card tests one idea.
- **Connected** — add examples, images, sounds, context, related ideas, or personal cues.
- **Meaningful** — remember material that supports something the learner cares about doing.

Repeatedly failed cards should be rewritten to be smaller, clearer, or better connected.

## Learning workflow

1. Try to do something meaningful.
2. Notice where progress gets blocked.
3. Learn the missing fact, distinction, or technique.
4. Turn it into a focused card.
5. Review it with active recall.
6. Return to the meaningful activity.

This keeps flashcards tied to use instead of becoming a disconnected collection of facts.

## Habit guidance

Start with about five new cards per day, attach review to a stable daily cue, and increase volume only after the routine is sustainable. A missed day is less important than protecting the long-term habit.

## Tools mentioned

- A physical Leitner Box is tactile and transparent but less portable and less capable with media.
- Anki automates scheduling and supports images and audio, though its interface can feel complex.
- The source also mentions SuperMemo, Mnemosyne, NimbleNotes, and the discontinued TinyCards.

## Main takeaways

- Spaced repetition is active recall distributed over time.
- Review should become less frequent as memory strengthens.
- Card quality matters: one idea, useful context, meaningful purpose.
- The best material to remember is material that supports real action.
