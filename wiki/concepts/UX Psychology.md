# UX Psychology

UX psychology is the use of behavioural principles to make product decisions feel easier, safer, and more worthwhile for users.

The practical aim is not to decorate a screen with persuasion tricks. It is to shape the task so the next action feels clear and valuable.

## Design Levers

### Reduce Cognitive Effort

Smart defaults reduce decision fatigue because users can scan and adjust instead of starting from a blank state.

### Create Honest Momentum

Progress systems should count something real the user already did. Starting at 20% can be motivating when it reflects an actual completed step.

### Give Value Before Asking

Signup prompts work better after the user has received a useful preview or result. Reciprocity should feel like trust-building, not a hostage exchange.

### Build Ownership

Customization, setup choices, and early creation can make a user feel invested before account creation. This is the same broad mechanism behind the investment step in [[Hook Model]].

### Frame Cost in Context

Loss aversion and contrast effects change how users evaluate upgrade prompts and pricing. The ethical line is accuracy: do not fake scarcity, urgency, progress, results, or social proof.

## Product Design Questions

- What can be pre-filled without hiding important choice?
- What has the user already done that can count as progress?
- What useful value can be shown before signup?
- What can the user create or personalize before being asked to commit?
- What comparison should the user see before judging price or effort?
