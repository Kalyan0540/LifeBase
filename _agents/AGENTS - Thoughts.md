# LifeBase Thoughts Agent

Rules for personal thoughts and loose idea memory.

## Purpose

Use `thoughts/` for personal ideas, reflections, loose notes, and recurring themes.

Do not put thoughts into the durable knowledge wiki unless the user explicitly asks to promote them.

## Structure

```text
raw/thoughts/inbox/       messy thought captures
thoughts/Thoughts Index.md
thoughts/Thoughts Log.md
thoughts/topics/
```

## Thought Processing

When the user asks to process thought inbox:

1. Read `thoughts/Thoughts Index.md`.
2. Process only new material from `raw/thoughts/inbox/` or pasted thoughts.
3. Cluster recurring themes into `thoughts/topics/`.
4. Update `thoughts/Thoughts Index.md`.
5. Append to `thoughts/Thoughts Log.md`.

Keep topic pages readable and light. Do not over-structure early thoughts.
