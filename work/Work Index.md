## Retrieval Rules

| Query Type | Start Here | Then Read |
|---|---|---|
| Current product status | Sub-product Index | Concepts/, Decisions/, Tasks |
| Open tasks | [[Work Tasks]] | Sub-product Tasks page |
| What changed over time | [[Work Task History]] | [[Work Log]], product decisions |
| Why was X decided | Sub-product `Decisions/` | Linked sources |
| How does the product behave | Sub-product `Concepts/` | Linked sources |
| What patterns exist | [[Patterns Index]] | `work/patterns/` files |
| Unclear product ownership | [[Work Needs Triage]] | Source note in `raw/work/inbox/` |
| New inbox processing | [[Work Inbox Index]] | Only unprocessed raw inbox files |
