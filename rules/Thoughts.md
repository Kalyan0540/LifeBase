# Thoughts Rules

Use `thoughts/` for personal ideas, reflections, loose notes, and recurring themes.

Do not put thoughts into the durable knowledge wiki unless the user explicitly asks to promote them.

## Structure

```text
raw/thoughts/inbox/     messy thought captures
raw/thoughts/assets/    attachments for thought captures
thoughts/Thoughts Index.md
thoughts/Thoughts Log.md
thoughts/topics/
```

## Reading Rules

- For thought queries, start with `thoughts/Thoughts Index.md`.
- Read topic pages only when the index points to them or the user asks for detail.
- Read raw thought captures only during processing or when the generated topic page is not enough.

## Thought Processing

When processing thought inbox:

1. Read `thoughts/Thoughts Index.md`.
2. Process only new material from `raw/thoughts/inbox/` or pasted thoughts.
3. Add recurring themes to `thoughts/topics/`.
4. Update `thoughts/Thoughts Index.md`.
5. Append to `thoughts/Thoughts Log.md`.

Keep topic pages readable and light. Create a new topic only when a thought is likely to recur or be retrieved later.
